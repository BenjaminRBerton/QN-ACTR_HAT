See \QN docs folder for QN-ACTR manual.


Quick start:

1. Get IntelliJ IDEA Java IDE (tested with 2021 version)

2. Unzip QN-ACTR-master.zip.

3. In IntelliJ, open QN-ACTR-master project folder.

4. Specify a model in QN_ACTR_Model_Initialization.txt (or copy from an existing model file) under \QN-ACTR-master\out\production\QN workspace\HMI_1. 

5. To start simulation, run jmt.gui.jmodel.mainGui.MainWindow.java under src from the project explorer or navigator.
